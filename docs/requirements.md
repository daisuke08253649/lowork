# 要件定義書（ドラフト）
> 最終更新: 2026-06-24

---

## 1. プロダクト概要

### コンセプト
**普通のチャット**と**プロジェクトチャット**の2モードを持つローカルAIアシスタント。プロジェクトチャットではRAGによりフォルダ内のファイルを自動で読み込み、新規作成・編集まで行う。LLMを含め**完全ローカルで動作**する。

### 一言で言うと
「自分のMarkdownノートを理解して、ファイルを作ったり整理してくれるオフラインAIアシスタント」

---

## 2. ターゲットユーザー

- **一次ユーザー**: 開発者本人
- **二次ユーザー**: 同様の用途を持つエンジニア・個人開発者（属性は現時点では未定義）

---

## 3. 解決する課題

- クラウドLLMはプライバシーリスクがあり、ローカルの個人ノートを渡したくない
- APIコストがかかる
- オフライン環境でも使いたい
- ファイル操作をチャットだけで完結させたい（ファイルを手動で開く手間をなくす）

---

## 4. コアUX

### 普通のチャット
1. ユーザーがチャット画面でOllamaと自由に会話する
2. RAG・ファイル操作は行わない

### プロジェクトチャット
1. ユーザーがプロジェクト（フォルダ）を作成・選択する
2. チャット画面に指示を入力する
3. AIがプロジェクトフォルダ内から関連ファイルを自動検索・読み込む（RAG）
4. AIが指示に基づきファイルを**新規作成**または**既存ファイルを編集**する
5. 結果がサイドバーのファイルツリーに反映される

### 操作例（プロジェクトチャット）
- 「〇〇についてのメモを作って」→ 新規Markdownファイルが生成される
- 「〇〇に関連する内容をまとめた新しいファイルを作って」→ 複数ファイルを参照した統合ドキュメントが生成される
- 「〇〇のファイルをもっと詳しく書いて」→ AIが該当ファイルを自動で見つけて編集する

## 5. 機能要件

### MVP（初回リリース）

| 機能 | 概要 |
|------|------|
| 普通のチャット | RAG・ファイル操作なしでOllamaと自由に会話できる |
| プロジェクト管理 | プロジェクト（フォルダ単位）を新規作成または既存フォルダから選択・切り替え・削除できる。複数プロジェクトに対応 |
| ファイル保存先 | AIが生成した新規ファイルはプロジェクトフォルダ直下に保存する。ファイル名はAIが自動決定する |
| インデックス構築 | フォルダ追加時にバックグラウンドで実行。進捗はサイドバー下部またはステータスバーに非侵襲的に表示する |
| RAG検索 | 指定フォルダ内のMarkdown・テキストファイルをベクトル化し、チャット時に自動で関連ファイルを検索・読み込む |
| ファイル新規作成 | チャット指示に基づき新規ファイルを生成・保存する |
| ファイル編集 | チャット指示に基づき既存ファイルを自動で見つけて編集する |
| 実行モード切り替え | **確認モード**（diff表示 → ユーザー承認後に書き込み）と**自走モード**（即時実行）をトグルで切り替えられる |
| チャットUI | チャット形式でAIと対話できる |
| モデル切り替え | Ollamaで利用可能なモデル一覧をドロップダウンで表示・切り替えできる |
| 設定画面 | モデル名を指定してOllamaからダウンロード（pull）できる |
| ファイルツリー | サイドバーにRAG対象フォルダのファイルツリーを表示する |
| Ollama連携 | ローカルで起動中のOllamaと連携してLLMを呼び出す |
| チャット履歴 | 普通のチャット・プロジェクトチャット両方の会話履歴をローカルに保存し、アプリを閉じても復元できる |

### 将来的な機能（スコープ外）

- Windows / Linux対応
- ファイルのプレビュー表示
- 複数チャットセッション管理

---

## 6. 非機能要件

| 項目 | 方針 |
|------|------|
| オフライン動作 | LLM・RAG含め完全ローカルで動作すること |
| プラットフォーム | macOS（初回リリース） |
| UI言語 | 日本語固定（初回リリース） |
| プライバシー | 外部サーバーへのデータ送信なし |
| エラーハンドリング | Ollamaが起動していない場合はUI上にわかりやすいエラーを表示する |

---

## 7. 技術スタック

| レイヤー | 技術 |
|------|------|
| デスクトップシェル | Tauri（Rust） |
| フロントエンド | React / shadcn/ui（Tailwind CSS） |
| バックエンド | Python（FastAPI）※Tauriサイドカーとして起動 |
| LLM | Ollama（ローカルAPI） |
| RAG | LangChain |
| ベクトルDB | ChromaDB（ローカル） |
| チャット履歴DB | SQLite（ローカル保存） |
| 対応ファイル形式 | Markdown（.md）、テキスト（.txt） |

## 8. 画面構成

### 画面一覧
- プロジェクト一覧画面（プロジェクトの作成・選択・削除）
- 普通のチャット画面（左パネル：チャット履歴一覧 / 右パネル：チャット）
- プロジェクトチャット画面（左パネル：ファイルツリー / 右パネル：チャット）
- 設定画面（モデルのダウンロード・管理）

※各画面の詳細レイアウトは設計書で定義する
