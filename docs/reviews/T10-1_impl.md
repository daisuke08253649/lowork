# T10-1 実装サマリー（設定・チャットUIの操作性改善）

## 実装内容

- 設定画面で、互換性が「判定不能」または「ダウンロード不可」のモデルはダウンロードボタンを無効化した。ダウンロード可能・動作が重くなる可能性のあるモデルは従来どおり操作できる。
- モデル一覧に「すべて」「Qwen」「Kimi」「GPT」「Gemma」のカテゴリフィルタを追加した。カテゴリ名はモデル名の接頭辞と大文字・小文字を区別せず照合し、該当モデルがあるカテゴリだけを表示する。
- プロジェクトチャット画面では、左サイドバーの見出しを「プロジェクトチャット履歴」に変更した。通常チャットなどの画面では「チャット履歴」のままとした。
- 「このプロジェクトで新しい会話」ボタンを、モデル選択と実行モード切替の上の独立行へ移動した。既存のURL遷移、送信中の無効化は変更していない。
- 共通のメッセージ入力欄で、送信ボタンを横長に変更し、Enterで改行・Shift+Enterで送信する操作へ変更した。IME変換中は送信しない。

## レビュー対応（第1回）

- `GET /ollama/available-models` が、バックエンドで使用する`OLLAMA_EMBEDDING_MODEL`を返すようにした。設定画面はそのモデルだけを判定不能でもダウンロード可能とし、RAG機能のセットアップ経路を維持する。
- 判定不能で無効なダウンロードボタンには、無効理由をツールチップで示すようにした。カテゴリ操作部には`role="group"`を付与した。
- メッセージ入力欄に画面高の40%という最大高さと内部スクロールを設定し、長文入力で送信操作が画面外へ押し出されないようにした。プレースホルダにもEnter/Shift+Enterの操作を記載した。
